## 1. 章節概述

### 1.1 章節名稱

**第二章：螢苔祕林**

英文名稱：**Chapter 02 --- The Glowmoss Wood**

章節主題句：

> 當森林忘記了如何呼吸，星光便開始消失。

### 1.2 章節定位

第一章「晨曦谷地」負責讓玩家熟悉移動、探索、互動與基礎戰鬥；第二章「螢苔祕林」開始引入更完整的探索循環，包括環境謎題、採集製作、NPC
任務、精英怪、多階段 Boss，以及更深層的世界觀線索。

本章不可只被視為換一張地圖。所有地圖、道具、怪物、任務與場景機關都必須服務於「森林生命循環遭到污染」的核心主題。

### 1.3 設計目標

1.  建立具有明確地標與探索節奏的半開放式森林地圖。
2.  讓玩家透過觀察、互動與戰鬥逐步理解迷霧異變。
3.  提供主線、支線、採集、製作、隱藏區域與章節 Boss。
4.  保持可愛、精緻、低多邊形（Stylized Low-poly）的視覺風格。
5.  讓單人遊玩完整可行；多人合作是加值體驗，不得成為主線通關的必要條件。
6.  資產、任務、怪物與互動邏輯需模組化，方便後續章節重用。
7.  控制首版製作規模，先完成一段垂直切片，再擴充整章。

### 1.4 章節體驗目標

首次遊玩預估約 2.5--4
小時，實際時間依探索程度、戰鬥難度與玩家熟悉度調整。

玩家完成本章後，應該： - 熟悉至少一種環境解謎機制。 -
學會使用星光／照明道具探索迷霧。 - 擊敗一般怪物、精英怪與章節 Boss。 -
接觸採集、製作、商店及任務獎勵。 -
理解迷霧並非普通天氣，而與星光共鳴失衡有關。 -
獲得前往第三章「澄鏡湖」的明確動機。

## 2. 世界觀與劇情設定

### 2.1 區域背景

螢苔祕林曾是整個森林的生命循環中心。古老樹木將星光轉化為生命能量，螢苔將能量傳遞到地下根系，螢火蟲與森林精靈則將星光帶往更遠的土地。

近期，森林出現一連串異常： - 螢苔失去光芒，部分植物被紫黑色菌絲覆蓋。 -
森林動物開始攻擊旅人。 - 溪水逆流，古老根系向地表蔓延。 -
迷霧中出現無法辨識的聲音與幻影。 - 古樹祭壇的生命核心逐漸被污染。

### 2.2 核心真相

迷霧不是單純的自然現象，而是星光共鳴失衡後的結果。某種外力曾經改變古老共鳴力量的流向，造成污染在森林內累積。

古樹守護者「根噬者」並非污染的始作俑者。牠正在將污染封鎖於祕林深處，卻因長期承受侵蝕而失控。玩家的目標不是摧毀森林，而是修復生命循環並淨化守護者。

### 2.3 劇情節奏

1.  **進入祕林：** 玩家受晨曦谷地居民委託，調查星光消失與動物異常。
2.  **修復生命循環：** 玩家點亮燈柱、採集純淨螢苔、修復倒流溪谷。
3.  **取得居民信任：** 協助蘑菇聚落，獲得深入森林的線索。
4.  **發現人為痕跡：** 古代石碑指出星光共鳴曾被人為改變。
5.  **進入深層迷霧：** 玩家面對精英怪與污染根瘤，逐步接近古樹祭壇。
6.  **淨化根噬者：** 透過戰鬥與共鳴機關解除污染。
7.  **前往澄鏡湖：**
    古樹記憶顯示下一個線索位於湖面，並留下神祕旅人的伏筆。

### 2.4 章節結尾台詞草案

古樹核心恢復金色光芒後，玩家看到一段澄鏡湖的記憶。無名旅人留下訊息：

> 「如果你想知道是誰奪走森林的星光，就去看看湖中那個不屬於你的倒影。」

此段用來銜接第三章，不應在第二章一次揭露全部反派背景。

## 3. 美術聖經與視覺規範

### 3.1 整體風格

-   Stylized Low-poly 3D。
-   可愛、圓潤、易辨識的角色比例。
-   造型簡潔，但輪廓與材質需有精緻度。
-   場景有清楚的前景、中景、遠景與景深層次。
-   避免寫實恐怖、過度尖銳、血腥或陰暗到無法辨識互動物件。
-   畫面品質應以完成度高的遊戲場景為目標，不以單純幾何方塊拼接作為最終呈現。

### 3.2 色彩方向

  用途         主色方向                 使用原則
  ------------ ------------------------ --------------------------
  一般森林     苔綠、草綠、木材棕       主要環境基色
  螢苔與星光   青綠、湖水藍、柔和金色   引導探索、標示可互動目標
  污染與迷霧   紫色、紫黑、低飽和藍灰   危險區域與敵對能量
  聚落         暖棕、米黃、橙色燈光     提供安全感與生活氣息
  古代遺跡     石灰、青藍晶體、古金色   強調歷史與魔法科技

### 3.3 光照與特效

-   一般森林使用柔和環境光與體積感霧氣。
-   螢苔、蘑菇與星晶使用有限度的自發光效果。
-   紫色污染應有緩慢流動的粒子或脈動效果，不得遮蔽地形與攻擊提示。
-   Boss 戰階段變化需以光照、地面圖樣、音效和動畫共同提示。
-   互動物件應使用一致的高亮或提示規則。
-   避免全場高亮與過量粒子造成視覺雜訊或效能下降。

### 3.4 角色比例與一致性

主角沿用專案既有角色設計與
`ART_BIBLE.md`。若主角使用古羅馬女性冒險者造型，應保留棕色編髮、金色月桂冠、米白色羅馬束腰長衣、酒紅色披風、古銅金護腕、皮革腰帶與羅馬涼鞋等識別元素。第二章裝備只做合理的局部升級，不應每章重置角色外觀。

所有新角色、怪物與道具概念圖必須遵循專案美術規範，並在進入正式建模前檢查輪廓、比例、材質、色彩與三視圖需求。

## 4. 世界地圖與區域規格

### 4.1 地圖架構

採用「半開放式地圖 + 多路線探索 + 階段解鎖區域」。

不要求首版將所有區域製作成完全無縫的大型開放世界。可依現有引擎與載入架構選擇： -
同一張世界地圖內分區載入；或 -
多個相連場景，以自然入口、隧道、霧門或過場連接。

地圖拓樸、區域解鎖條件與任務進度必須由資料設定，不可散落在各場景元件中硬編碼。

### 4.3 區域設計原則

每個區域至少包含： - 一個可從遠處辨識的地標。 -
一條主要路線與至少一個探索分支。 - 一種主要環境互動。 -
一組環境素材與可重用物件。 - 一個玩家能理解的進入／離開方向。 -
一個獎勵或劇情回饋。 - 清楚的碰撞、導航與邊界設計。

隱藏區域可以提高探索獎勵，但不得把主線必要道具放在沒有提示的隱藏路線中。

### 4.4 地圖導引

-   以地標、燈光、路徑材質與植物分布引導玩家，不要只依賴箭頭。
-   星光羅盤可在玩家主動使用時標示附近的星光殘留。
-   主線目標需能從任務追蹤介面查看。
-   玩家迷路時，應能從地圖、羅盤或 NPC 提示恢復方向。
-   迷霧可降低遠距離能見度，但不得完全遮蔽必要的跳躍落點、敵人預警或互動提示。

## 6. 怪物與 Boss 規格

### 6.1 怪物設計原則

-   外型可愛、輪廓清晰，但戰鬥行為要有差異。
-   每種怪物至少具備待機、移動、攻擊、受擊、死亡動畫；必要時增加技能或特殊狀態動畫。
-   攻擊前應提供可讀的前搖、動作或地面提示。
-   怪物掉落、生成位置、巡邏範圍與重生規則應資料化。
-   不可只用更高血量區分怪物；每種敵人應迫使玩家使用不同應對方式。

### 6.2 普通怪物

#### M-01 螢苔史萊姆

-   定位：新手近戰怪。
-   出現區域：A、B。
-   行為：巡邏、發現玩家後跳躍撞擊，低血量時可分裂成小型史萊姆。
-   攻擊：跳躍撞擊、短距離黏液噴射。
-   弱點：星光攻擊。
-   掉落：螢苔凝膠、微光孢子。

#### M-02 菌帽小妖

-   定位：群體近戰、擾亂玩家。
-   出現區域：B、D 外圍。
-   行為：躲藏、成群接近、攻擊後撤退。
-   攻擊：木棒敲擊、孢子煙霧。
-   特性：部分個體會嘗試拾取地上的可拾取物。
-   掉落：菌帽、柔韌樹皮。

#### M-03 霧紋森林狼

-   定位：高速突進怪。
-   出現區域：C、E。
-   行為：繞行、蓄力、突進、短暫硬直。
-   攻擊：突進、連續撕咬。
-   特性：可呼叫附近同伴，但不得無限生成敵人。
-   掉落：霧紋獸牙、厚實獸皮。

#### M-04 幻霧螢靈

-   定位：遠程魔法與位移。
-   出現區域：E、F。
-   行為：保持距離、發射追蹤光球、短距離瞬移。
-   攻擊：追蹤光球、短暫致盲。
-   弱點：螢光提燈照射後短暫現形。
-   掉落：螢靈翅粉、微型星晶。

### 6.3 精英怪 M-05：枯根守衛

-   定位：區域精英怪／小魔王。
-   出現區域：E 的根系巢穴。
-   外觀：體型約為玩家的 2--3
    倍，木質軀幹、粗大根臂、胸口有紫色污染晶核。
-   第一階段：手臂揮擊、踩踏。
-   第二階段：地面根刺，核心短暫暴露。
-   戰鬥要求：玩家觀察攻擊前搖、移動離開危險區，並在核心暴露時輸出。
-   掉落：守衛木核、稀有樹脂。
-   完成後：移除附近污染根瘤，解鎖通往祭壇的路線或關鍵線索。

### 6.4 章節 Boss B-01：腐化古樹守護者・根噬者

#### 基本設定

-   場地：G「古樹祭壇」。
-   定位：第二章最終 Boss。
-   主題：原本保護森林的守護者受到污染，並非真正的敵對意志。
-   戰鬥目標：擊敗污染、啟動共鳴石柱、完成淨化，而非單純殺死守護者。

#### 第一階段：失控的守護者

-   大範圍手臂揮擊。
-   地面根刺突襲。
-   胸口污染核心在攻擊後短暫暴露。
-   教會玩家觀察動作與抓住輸出時機。

#### 第二階段：迷霧暴走

-   場地出現紫色迷霧區域。
-   Boss 召喚幻霧螢靈。
-   玩家需啟動三座共鳴石柱，建立安全區或降低 Boss 防禦。
-   單人模式下機關必須可由一名玩家依序完成。

#### 第三階段：星光淨化

-   Boss 攻擊頻率降低，核心呈現金紫交錯狀態。
-   玩家利用星光共鳴打斷污染循環。
-   完成指定互動後進入淨化過場。
-   Boss 不以血量歸零直接死亡，而是進入淨化與劇情結算。

#### Boss 戰驗收要求

-   攻擊範圍清楚，玩家可合理預測與躲避。
-   階段切換有動畫、音效或 UI 提示。
-   Boss 進入階段轉換時，避免玩家因不可控連擊而死亡。
-   多人模式若啟用，Boss 狀態需由權威端統一管理。
-   重試時能正確重置 Boss、機關、召喚物與戰鬥區域狀態。
-   完成戰鬥後，任務獎勵與劇情只結算一次。

## 9. 環境謎題與互動玩法

### 9.1 謎題 P-01：星光燈柱

**目標：** 點亮入口與花園中的三座燈柱。

流程： 1. 玩家找到燈柱。 2. 觀察周圍發光植物或古代符號。 3.
收集純淨螢苔。 4. 互動啟動燈柱。 5.
燈柱點亮，局部迷霧降低，附近路徑或採集點顯現。

驗收： - 玩家能從視覺提示理解燈柱可互動。 - 素材不足時有明確提示。 -
完成後不會重複消耗材料。 - 重新載入存檔後保留正確狀態。

### 9.2 謎題 P-02：倒流溪谷水輪

**目標：** 修復三個水輪，讓溪流恢復正確方向。

流程： 1. 觀察水流與水輪的關係。 2. 移動石塊或啟動附近機關。 3.
依序啟動水輪。 4. 橋梁或水位發生變化，開啟新路線。

驗收： - 水輪有未啟動、啟動中、完成三種可辨識狀態。 -
機關順序可由環境線索推導。 - 不得因跳躍或角色卡位導致無法繼續。 -
單人模式可以完成全部步驟。

### 9.3 謎題 P-03：星晶反射機關

**目標：** 將光線導向古代石門。

流程： 1. 玩家調整可旋轉晶體。 2. 光線經過不同反射面。 3.
所有光束對準指定符文後開門。 4. 獎勵區出現，並記錄古代歷史。

驗收： - 反射方向有清楚的視覺回饋。 - 可旋轉物件具有互動提示。 -
若玩家離開區域再返回，機關狀態仍正確。 -
若有重置機關功能，需清楚提示其影響。

-   Boss 戰失敗時可重試，且正確重置敵人和機關。

若現有技能系統尚未支援多種能力，優先實作一個共用技能介面與一個完整可玩的星光技能，不要為本章建立完全獨立的技能系統。

淨化／擊敗狀態。 - 章節結尾與第三章解鎖狀態。

機關狀態需由權威遊戲狀態決定。 - Boss
血量、階段、召喚物與獎勵不可由每個客戶端各自決定。 -
掉落物需定義拾取權、歸屬與重生規則。 -
玩家中途加入或離線時，需能取得正確的區域與任務狀態。 -
多人協作機關必須同時提供單人可完成的替代流程。

## 16. 首版範圍與暫不包含項目

### 首版必須完成

-   迷霧入口與螢苔花園垂直切片。
-   基礎採集、互動與任務系統整合。
-   至少一種普通怪物完整戰鬥流程。
-   星光燈柱解謎。
-   任務狀態與存檔正確。
-   可重用的場景資產與資料結構。

### 完整章節目標

-   七個區域。
-   四種普通怪物與一種精英怪。
-   一個三階段 Boss。
-   四名主要 NPC。
-   八個主線任務與六個支線任務。
-   核心道具、素材、裝備、製作與圖鑑。
-   章節結尾與第三章銜接。

### 暫不列為首版必要功能

-   大型多人公共伺服器與大量玩家同場。
-   複雜公會、交易市場或玩家經濟。
-   程序化無限地圖。
-   所有 NPC 全語音演出。
-   大量獨立動畫與完全客製化的每隻怪物。
-   需要多人同時操作才能完成的主線謎題。

以上功能可在核心遊戲循環穩定後再評估。
